# Pawster Social Preview / 分享预览图

`social-preview.jpg` is the 1280 × 640 repository share image. Its HTML/CSS source reuses the existing app icon and contains no version-specific wording. Open `social-preview.html` locally, render at 1280 × 640, and capture a PNG or JPG under 1 MB when updating it. Repository settings → General → Social preview controls the published image; committing this file alone does not change that setting.

分享图沿用现有猫咪图标，HTML/CSS 为可编辑来源，不含特定版本信息。更新时以 1280 × 640 渲染，PNG/JPG 保持小于 1 MB，并在仓库设置的 Social preview 中上传；仅提交文件不会自动更新该设置。
