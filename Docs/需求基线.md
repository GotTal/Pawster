# 需求基线（2026-11-11）

用户已确认：开发独立 iPhone 壁纸工具；接受配对文件和 LocalDevVPN；使用 AirCard-iOS 的 InstallationProxy 路径发现方式；旧版使用 bad_query，新版使用 worse_query；首版覆盖上游 bad_query 已列范围并优先验证 iPhone18,1 / iOS 27.2.1；首版只支持 Collections .tendies，包括 StudyFriends。

新增要求：用户进入开发者模式设置时，提供小窗，显示目标设置页面、配对项和开始配对后的真实六位配对码。画中画是否可跨设置页面稳定运行须实机确认，应用内步骤卡必须可用。

默认行为：先只读检查，再预览，再确认写入；保留原有壁纸；不清空 Collections，不替换数据库，不默认重启；缓存失效时重新查询；不因 ENOATTR 单独判定路径无效；所有句柄和配对会话有生命周期管理。

验收分别记录：路径身份通过、文件写入及校验完成、刷新完成、系统图库可见和实际使用成功。前三者不能替代最后两者。

交付目标：完整源码、构建和测试流程、经构建验证的可侧载 IPA、中文使用及实机检查说明。当前 Windows 交付只包含源码和本机能完成的检查；IPA 构建仍需 macOS/Xcode。

2026-11-13 增补：新增原版 Pocket Poster 的 Collections .Trash/trashItem 路径，最低部署版本 17.0；只按明确来源保守启用 17.0–18.7.2 和 26.0–26.1，手动 UUID 不强制网络配置。新增范围属于源码启用，尚未构建或完成喵贴实机确认；不将原版与 worse_query 分支混为一谈。
