# 0.2.0 发行检查

本次按用户 2026-11-13 的明确授权，将 `testing/pairing-pip` 合并至 `main` 并发布 0.2.0。后续修复仍先使用测试分支。

## 已调整

- 正式应用版本改为 0.2.0；CI 使用运行序号生成 build number。内部 Rust 库仍保留自身 0.1.0 包版本，不用于显示 App 版本。
- main 使用 release 通道和正式中英文应用名称；测试分支继续带 test 标识，应用标识与 App Group 保持一致，覆盖安装而不能并存。
- 英文 README 与中文 README_CN 采用已预览的结构，标题下互相跳转；安装入口指向 Release，不再依赖会过期的 Actions 附件。
- 加入 Ed25519 文件签名、公钥证书、固定指纹、签名及摘要检查工具。私钥仅在发布者本机通过 Windows DPAPI 加密保存；CI 权限仍为 `contents: read`。
- 新增 8 项文件验签测试，覆盖内容篡改、清单篡改、错误证书、签名替换、附件缺失及不安全路径；已在 Windows 通过，并加入正式构建检查。
- 保留所有第三方署名，另补上 idevice 的上游 MIT 全文；未将缺少明确授权的来源自行改为 GPL。

## 发布证据

正式 Release 附带 `release.json`、`SHA256SUMS`、清单与 IPA 分离签名、公钥证书及固定来源提交的源码归档。`release.json` 记录实际通过的 main 构建，不复用测试 IPA。具体构建结果和文件摘要以该签名清单与 GitHub Release 为准。

## 后续应完善

- 真实设备复核：SideStore 重签后的 App Group、配对引导小窗自动开关、VPN 路径查询、注入/注册/撤回及 NeoSpring；自动化通过不能替代这些验收。步骤见[实机验证](实机验证步骤.md)。
- 上游授权：bad_query 缺少独立 LICENSE，idevice-ffi 快照缺少独立许可声明，NeoSpring 进一步来源未见独立许可。这些是仍需取得依据的发行事项，不能由本项目的 GPL 声明补足。完整情况见[来源说明](../ThirdParty/SOURCES.md)。
- 依赖清单包含开发和多平台包，仍需按实际二进制完善授权核对与缺失许可文本。
- 仓库维护者应保护签名 Windows 账号及恢复材料，记录公钥轮换流程；DPAPI blob 不能当作可跨机器恢复的完整备份。
- 后续可按协作规模配置分支保护、必需检查与发布审批。当前不擅自改变仓库管理规则。
- 每次正式发布更新版本、对应验签文件名和源码链接，保持 tag、构建提交、源码归档和 IPA 一致。不可移动已发布 tag 或替换同名资产后沿用原签名。
