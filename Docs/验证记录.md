## 0.1.1：自动配对小窗与黑屏修复

用户提供的 0.1.0 实机截图证明画中画窗口能够启动，但内容为空；截图也显示系统配对输入页面。这不等于已确认配对成功或壁纸注入成功。本轮没有直接操作用户手机。

本轮修改：

- 将图像复制改为直接在 IOSurface 支持的 BGRA 像素缓冲中绘制，解锁后再入队；使用主机时钟时间戳，并直接修改 Core Media 原始 CF 附件字典设置立即显示标记。
- 使用 sampleBufferRenderer，并显示生成或渲染错误，避免静默黑屏。
- 使用系统自动 inline PiP，移除手动开窗按钮；把可见视频源移到所有标签页共用的顶部。
- PairingService 直接管理引导更新与结束，不再由 SwiftUI 对 running 的变化立即关闭小窗。
- 成功先清除 PIN，显示“配对成功”约 3 秒，再停止 PiP 和后台音频。失败、超时、取消也清除 PIN 并结束展示；会话标识防止旧关闭计时器误关新会话。
