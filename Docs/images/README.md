# UI screenshots / 界面截图

Six unedited PNG captures of the actual app in a clean iPhone simulator, generated by [CI run 43340977128](https://github.com/GotTal/Pawster/actions/runs/43340977128) from commit `4b5b8a8a2ddaa5001d3792bb97476e913599d880`. App runtime source was unchanged from the 0.2.0 release. English and Simplified Chinese each include the empty wallpaper library, the first setup step and the welcome/consent screen.

`Scripts/capture-doc-screenshots.sh` installs the tested simulator app and uses launch arguments to select language and synthetic preference states. It does not pair a device, import personal files or install wallpapers. These screenshots illustrate UI; they do not establish real-device compatibility. Existing artwork and third-party notices retain their original terms.
