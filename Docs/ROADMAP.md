# Project Priorities / 项目方向

This is a list of areas where contributions are useful, not a release schedule or compatibility promise. Discuss larger changes before implementation.

| Area | Useful contribution |
| --- | --- |
| Device confidence / 实机验证 | Reproducible reports using the compatibility form, starting with read-only checks |
| Languages / 多语言 | Additional locale packs, localized offline documents and metadata using the mapping specification |
| Setup / 新手体验 | Clearer instructions for common VPN, Developer Mode and pairing failures |
| Accessibility / 无障碍 | Large text, VoiceOver, contrast and reduced-motion feedback |
| Reliability / 可靠性 | Focused tests for cancellation, cleanup, archive validation and transaction recovery |
| Third-party provenance / 来源授权 | Verifiable permission records and missing license texts for existing dependencies |

See [open tasks](https://github.com/GotTal/Pawster/issues?q=is%3Aissue%20is%3Aopen) and the [contribution guide](../CONTRIBUTING.md). Maintainers review system-version expansion separately; new engine policy requires evidence, not a version-number substitution.

欢迎参与上述方向；没有承诺发布日期。现有版本与真实手机行为的验证边界保留在兼容性文档中，新增系统支持需另行评估。
